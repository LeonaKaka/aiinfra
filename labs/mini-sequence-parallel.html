LAB A8 · SEQUENCE PARALLEL

SP 不是“把句子随便切两半”。
关键是：TP 的 partial output 可以直接落成 sequence shard。

05.3 里讲过 Sequence Parallel (SP) 通常和 Tensor Parallel (TP) 配合。这个最小实验只验证最核心的一次 layout transition：两个 TP ranks 各自产生完整 sequence 的 partial output，不先 all-reduce 成两份完整 activation，而是用 reduce-scatter 一边求和、一边让每个 rank 只留下自己的 sequence chunk。

01 · THE TRANSITION

同样是把 TP partials 合起来，结果可以 replicated，也可以 sequence-sharded。

MENTAL MODELTP=2
Rank 0: y_partial[0] ─┐
                      ├─ reduce-scatter over sequence ─→ Rank 0 owns tokens 0..S/2-1
Rank 1: y_partial[1] ─┘                               └→ Rank 1 owns tokens S/2..S-1

all-reduce      : every rank gets full [S,H]
reduce-scatter  : every rank gets only [S/TP,H]

这个差别就是 SP 的系统价值来源之一：后续某些可以按 token 独立执行的 activation-side work，不必在每个 TP rank 上继续保留完整 sequence。

02 · CORRECTNESS REFERENCE

我们故意选一个简单局部算子，只验证“切分不改变数学结果”。

TP LOCALx_shard @ W_shard每个 rank 只算自己的 hidden-input shard，得到完整 [S,H] partial contribution。
SP TRANSITIONreduce_scatter_single对 TP partials 求和，同时沿 sequence 把结果分给不同 ranks。
LOCAL OPtanh(sequence shard)每个 rank 只处理自己的 token chunk；最后为了验证才 all-gather 回完整 sequence。

reference 是直接计算 tanh(x @ W)。实验只要证明 gather 后结果一致，就说明“replicated full activation → sequence-sharded activation”没有改变数学语义。
