TRACK B · INFERENCE INFRA
LAB B1 · RAW KV HANDOFF

Mini KV Handoff

Rank 0 Prefill 产生连续 K/V；Rank 1 接收后直接 Decode，并与本地重算 prompt KV 的 reference 对齐。

核心问题远端 KV 能否等价接管模型状态？
 LAB B2 · BLOCK KV

Mini Block KV Handoff

加入 request metadata、固定 token blocks、physical KV pool 和 logical→physical block table，开始接近 vLLM 的真实问题。

核心问题逻辑序列如何脱离物理显存位置？
性能数字仍然不是这一阶段的目标。

默认 tensor 很小，CPU/Gloo 的 timing 也不代表 GPU/NCCL，更不代表 RDMA。当前四个实验的验收标准是：你可以预测每个 rank 持有什么、哪一步必须通信、通信后数值为何仍与单机 reference 一致。下一阶段才会放大 workload、异步化并进入 profiler。
