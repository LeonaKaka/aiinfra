LAB A · TRAINING INFRA

Mini Megatron TP

把两层 MLP 做成 Column Parallel + Row Parallel。每个 rank 只持有一部分权重，最后通过 all-reduce 恢复完整输出。

你会看到shard → local GEMM → all-reduce
 LAB B · INFERENCE INFRA

Mini KV Handoff

Rank 0 做 Prefill 产生 K/V，Rank 1 接收后直接做第一步 Decode，再和“在 Decode 端重算 prompt KV”的参考结果比较。

你会看到prefill → send KV → decode
这不是“迷你版框架”宣传。

两个实验只保留机制骨架：没有 Megatron 的完整并行拓扑，也没有 vLLM 的 paged KV、Scheduler、lease、异步 NIXL 或 RDMA。正因为删掉了这些工程层，你可以先把核心因果关系看清，再回到真实源码。
