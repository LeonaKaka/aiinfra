LAB A6 · 2D PROCESS GROUPS

一个 global rank 可以同时属于多个“世界”。
TP 通信和 DP 通信绝不能混在一起。

前五个 Training Labs 每次只盯一个并行维度。真正的 Megatron 会同时有 TP、DP、PP、CP、EP。这里先做最小二维拓扑：4 个进程组成 TP=2 × DP=2。每个 DP replica 内，两张卡一起算同一个样本的 TP layer；而相同 TP shard 的两个 replica，再通过另一组 DP group 同步参数梯度。

01 · DRAW THE GROUPS

同样四个 rank，按不同问题会被切成两套 group。

GLOBAL RANKSTP=2 · DP=2
                 TP rank 0     TP rank 1
DP replica 0        R0  ←──TP──→  R1
                    ↑             ↑
                    DP            DP
                    ↓             ↓
DP replica 1        R2  ←──TP──→  R3

TP groups = [0,1] [2,3]
DP groups = [0,2] [1,3]

R0 的身份不是单纯“global rank 0”。它同时是 TP group [0,1] 的 TP-rank 0，也是 DP group [0,2] 的 DP-rank 0。后面看 Megatron 的 tensor-model-parallel group / data-parallel group 时，必须带着这种二维坐标思考。

02 · TWO DIFFERENT COLLECTIVES

同一个 backward 里，两个 all-reduce 回答的是完全不同的问题。

TP GROUP[0,1] or [2,3]Row-parallel 输出 partial y 要求和；dX 也是来自不同 weight shard 的 contribution，要在 replica 内求和。
LOCAL SHARD GRADdW1[t] · dW2[t]参数 gradient 本身仍属于 TP shard t，不需要和另一个 TP shard 拼成同一个 gradient tensor。
DP GROUP[0,2] or [1,3]相同 TP shard 在不同数据 replica 上得到不同 dW；只和“同 shard 的副本”做 DP gradient sync。

这是理解多维并行最重要的一条：先问这次 collective 在哪个 process group 里，再问它是什么 collective。只看到 all_reduce 这个函数名，不足以知道它在解决什么问题。
