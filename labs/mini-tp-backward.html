LAB A2 · BACKWARD COMMUNICATION

Forward 会切矩阵还不够。
反向传播才告诉你通信为什么出现在那里。

上一实验只验证了 Column Parallel → Row Parallel 的 forward。这里把反向传播完整摊开：W1/W2 的梯度天然保持 sharded，但输入梯度 dX 会收到所有 W1 column shard 的贡献，所以必须跨 TP ranks 求和。理解这一步后，再看 Megatron mappings 里的 forward/backward collective 就不再像“魔法”。

01 · BACKWARD MAP

从 replicated dY 往回走，逐个问：这个梯度属于谁？

ROW-PARALLEL W2dW2 stays local每个 rank 只更新自己那几行 W2；dHidden 也只对应本 rank 的 hidden shard。
COLUMN-PARALLEL W1dW1 stays local每个 rank 只拥有 W1 的一组输出列，因此其 dW1 也天然是同一 shard。
REPLICATED INPUTdX needs all-reduce每个 column shard 只算出一部分 dX；前一层要完整 dX，就要把这些贡献相加。

这类推理比记“某层 backward 有 all-reduce”更可靠：只要知道张量是 replicated 还是 sharded，就可以重新推导通信。

02 · MANUAL GRADIENTS

脚本故意不用分布式 autograd，把公式写出来。

LOCAL BACKWARDper rank
dW2ᵣ = Hᵣᵀ · dY

dHᵣ  = dY · W2ᵣᵀ
dPreᵣ = dHᵣ ⊙ ReLU'(Preᵣ)

dW1ᵣ = Xᵀ · dPreᵣ
dXᵣ  = dPreᵣ · W1ᵣᵀ

dX = all_reduce_sum(dXᵣ)

只有最后一行跨 rank 聚合。实验为了检查数值正确性会额外 all-gather dW1/dW2 shards，把它们拼回 full gradient；那一步只是测试，不是训练算法本身的必需通信。
